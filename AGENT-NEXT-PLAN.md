# План следующему агенту — финальная интеграционная приёмка AST Code Canvas

## P0 — проверить живое Electron-приложение

1. Выполнить `npm ci`, `npm test`, `npm run build`, `npm start`.
2. Проверить ПКМ точно по Archify-узлу: должен появиться только пункт «Развернуть AST», а не штатное меню.
3. Проверить ПКМ по фону/обычной фигуре: штатное меню Excalidraw должно сохраниться.
4. Выбрать «Развернуть AST»: должен открыться полноразмерный overlay с listing-карточками и направленными связями, а не боковая панель.
5. Проверить «Сам узел / 1 уровень / 2 уровня», вкладки, Escape, × и возврат фокуса.
6. Закрыть overlay и убедиться, что zoom, pan, selection и содержимое Excalidraw не изменились.

## P0 — редактор

- сохранить небольшой файл из карточки;
- проверить обновление AST после save;
- изменить тот же файл извне при открытом editor и подтвердить отказ `STALE_PROJECT`;
- проверить запрет редактирования truncated listing.

## P1 — улучшения графовой сцены

- pan/zoom/fit-view внутри AST canvas;
- сохранение позиций карточек отдельно для own/L1/L2;
- подсветка рёбер выбранной карточки;
- cycle-aware layout и уменьшение пересечений при 20–50 карточках;
- minimap для больших anchor graph;
- code highlighting по языку.

## P1 — большие файлы

Текущий безопасный редактор работает только с полностью загруженными bounded listings. Для больших файлов добавить main-owned edit-session token и hash-gated range patch, не выдавая renderer-у полный файл.

## P2 — расширенное редактирование

- line numbers, поиск, переход к exact symbol range;
- diff-preview перед save;
- Undo последней записи;
- rename symbol с перечнем затронутых файлов;
- formatter/typecheck/test hook с rollback.

## Обязательные инварианты

- Excalidraw остаётся единственным владельцем основной сцены и не remount-ится.
- Renderer не знает абсолютный project root.
- Запись только в anchor-scoped существующий текстовый файл.
- Generation + snapshot обязательны.
- ПКМ вне Archify-компонента остаётся штатным.
- Drag/resize не считается щелчком раскрытия.


## Round 4 verification

После установки зависимостей обязательно выполнить живой цикл: открыть проект → Archify → подтвердить импорт → сохранить → ПКМ по каждому узлу. Проверить, что `customData.archify.astAnchor.own` непуст, L1 содержит непосредственных соседей, L2 — соседей через один переход, а повторное открытие сохранённого `architecture.excalidraw` сохраняет эти anchors.
